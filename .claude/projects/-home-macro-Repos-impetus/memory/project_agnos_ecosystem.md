name: AGNOS ecosystem component roles
description: Roles of key AGNOS projects — abaco is the math engine, impetus is the physics engine
type: project
---

Abaco is the math engine in the AGNOS ecosystem. Impetus (this project) is the physics engine and bridges abaco-core's unit system (UnitCategory) for type-safe quantities.

**Why:** Understanding component roles prevents mischaracterizing projects (e.g., calling abaco just a "units system" when it's the math engine).
**How to apply:** When referencing abaco, describe it as the AGNOS math engine, not merely a units library.
